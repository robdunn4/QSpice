QColorPrefs - Changelog

Version 1.3 - February 2026
----------------------------

NEW FEATURES:
* Added selective update functionality with new command-line options:
  - Added -uall option to update all existing keys in file with current registry values
  - Added -usch option to update only schematic keys in file with current registry values
  - Added -uwav option to update only waveform keys in file with current registry values
* Update operations preserve file structure and only modify existing keys
* Update operations require an existing file (error if file not found)
* Added test mode functionality with -t command-line option:
  - Shows what would change without making any changes (dry-run mode)
  - Works with all operations: save, update, and restore
  - Automatically shows verbose-style output
  - Skips user confirmation prompts for non-interactive testing
  - Reports only values that would actually change (not total count)
* Added verbose mode with -v command-line option:
  - Shows detailed before/after values for each setting
  - Per-section alignment for easy visual comparison
  - Works with all operations: save, update, and restore
  - Can be combined with test mode for maximum detail

CHANGES:
* Enhanced file headers with better metadata:
  - Added current date and time to first line
  - Shows "created" vs "modified" based on operation type
  - Removed confusing compile timestamp from version string
  - Clean version display (e.g., "v1.3" instead of "v1.3 [timestamp]")
  - Line 2 now always present for both save and update operations
* Improved output formatting and alignment:
  - Per-section alignment in verbose and test modes
  - Before values right-aligned within each section
  - Arrows (-> or ==) vertically aligned within each section
  - After values left-aligned within each section
  - Blank lines separate sections for clarity
  - Schematic and waveform sections align independently
* Enhanced test mode reporting:
  - Shows changed count instead of total count
  - Format: "Would change X value(s) (Y unchanged)"
  - Groups related info in parentheses
  - Clear hierarchy: primary, secondary, tertiary information
* Updated summary messages for better clarity:
  - Save to new file: "Would create new file with X value(s)"
  - Save to existing: "Would change X value(s) in: filename (Y unchanged)"
  - Update: "Would change X value(s) (Y unchanged, Z not in original file)"
  - Restore: "Would change X registry value(s) (Y unchanged)"
* Code improvements:
  - Removed unused includes (iomanip, sstream)
  - Fixed deprecated localtime() - now uses localtime_s() for Windows
  - Better error handling in date/time formatting
  - Cleaner code structure

DOCUMENTATION:
* Updated README_USER.txt with comprehensive user guide:
  - Added section on editing .qcolorpref files
  - Documented how to comment out entries to preserve personal preferences
  - Complete registry value reference (all 55 values documented)
  - Example of custom edited theme with commented-out preferences
  - Common settings users typically want to preserve
  - Expanded troubleshooting section
  - More detailed workflow examples
* Added inline comments in generated .qcolorpref files
* All registry values now have descriptive comments
* Comments aligned for readability within each section

BENEFITS:
* Allows maintaining customized .qcolorpref files with subset of keys
* Update refreshes values without adding unwanted keys
* Useful for version control (smaller, focused preference files)
* Test mode provides safe preview before committing changes
* Verbose mode shows exactly what changed for transparency
* Better metadata tracking with timestamps
* Users can share color-only themes (preserving personal size preferences)


Version 1.2 - February 2026
----------------------------

NEW FEATURES:
* Added selective save functionality with new command-line options:
  - Added -sall option to save all color settings (replaces -s)
  - Added -ssch option to save only schematic color settings
  - Added -swav option to save only waveform color settings
* Added verbose mode with -v command-line option:
  - Without -v: Suppresses warnings about missing registry values or file entries
  - With -v: Shows detailed warnings and diagnostic messages
  - Can be combined with any save or restore operation
* Added inline comments to preferences file format:
  - Each key=value pair can have a descriptive comment after # symbol
  - Comments are automatically generated from the RegistryValue definitions
  - Comments are aligned within each section for better readability
  - DataColor1-24 entries now show "Waveform Trace #N Color" comments
  - Comments are ignored during restore operations

CHANGES:
* Updated RegistryValue structure to include comment field for documentation
* Modified SavePreferences() function to:
  - Support optional section filtering (like RestorePreferences)
  - Generate aligned inline comments in output files
  - Calculate optimal padding for comment alignment within each section
* Modified RestorePreferences() function to:
  - Strip inline comments when parsing key=value pairs
  - Respect verbose flag for warning messages
* Enhanced command-line parsing:
  - -v flag can appear anywhere in argument list
  - More flexible argument processing
* Updated all DataColor entries (1-24) with descriptive comments
* Improved user feedback:
  - Shows skipped count when using section filters (in verbose mode)
  - Cleaner output in non-verbose mode

DOCUMENTATION:
* Updated readme.txt with new command syntax and examples
* Added documentation for inline comment format
* Added verbose mode usage instructions
* Updated RegistryValue configuration examples to show three-parameter format


Version 1.1 - February 2026
----------------------------

NEW FEATURES:
* Added selective restore functionality with new command-line options:
  - Added -rall option to restore all color settings (replaces -restore/-r)
  - Added -rwav option to restore only waveform color settings
  - Added -rsch option to restore only schematic color settings
* Users can now selectively update waveform or schematic colors without
  affecting the other section

CHANGES:
* Simplified command-line options:
  - Removed -save option (use -s instead)
  - Removed -restore option (use -rall instead)
  - Changed -r to -rall for clarity (restores all sections)
* Updated RestorePreferences() function to support optional section filtering
* Improved user feedback during restore operations:
  - Shows which section is being restored when using selective restore
  - Reports number of values skipped when using section filters
* Enhanced restore confirmation prompt to remind users to close QSpice before
  continuing

DOCUMENTATION:
* Updated readme.txt with clearer descriptions and better examples
* Added examples of selective restore operations
* Improved overview section to highlight selective restore capability
* Added safety features section explaining selective restore benefits


Version 1.0 - February 2026
----------------------------

INITIAL RELEASE:
* Command-line utility to save and restore QSpice color preferences
* Saves registry values to human-readable .qcolorpref text files
* Restores registry values from .qcolorpref files
* Supports two sections: schematic and waveform color settings
* Automatic .qcolorpref extension handling
* File overwrite protection with user confirmation
* Registry modification confirmation before restore
* Comprehensive error handling and user feedback
* Full list of QSpice color preferences pre-configured:
  - 20 schematic-related color settings (including 4 size/dimension values)
  - 25 waveform-related color settings (including 3 size/configuration values)
  - Total: 55 registry values

COMMAND-LINE OPTIONS:
* -s / -save: Save current registry values to file
* -r / -restore: Restore all registry values from file

SAFETY FEATURES:
* Prompts before overwriting existing files
* Prompts before modifying registry
* Clear error messages and warnings
* Validates file format and registry access

TECHNICAL DETAILS:
* C++11 compatible
* Windows Registry API integration
* REG_SZ (string) value support
* Organized preferences file with sections
* Comment support in preferences files
* Whitespace and blank line handling
* Cross-compiler support (MSVC, MinGW)


REGISTRY VALUES MANAGED:
-------------------------
QColorPrefs manages 55 total registry values in:
HKEY_CURRENT_USER\Software\Marcus Aurelius Software LLC\QSPICE\[Preferences]

SCHEMATIC SECTION (24 values):
  20 color values (CADHighlightColor, CADBackgroundColor, etc.)
  4 size/dimension values (JunctionSize, CADlineWidth, BUSwidthMultiplier, DefaultTextSize)

WAVEFORM SECTION (31 values):
  28 color values (BackgroundColor, FrameColor, DataColor1-24, etc.)
  3 size/configuration values (NumberDataTraceColors, WaveFormViewerFontPoints, WaveformPlotLineWidth)


FUTURE ENHANCEMENTS (Planned):
-------------------------------
* GUI version for users who prefer visual interface
* Support for additional QSpice registry values as they're added
* Preset theme library with built-in color schemes
* Color scheme preview without applying
* Import/export from other formats (JSON, XML)


KNOWN LIMITATIONS:
------------------
* Only supports REG_SZ (string) registry value types
* Requires QSpice to be closed for restore to take effect
* Windows-only (uses Windows Registry API)
* No undo functionality (user must maintain backups)


COMPATIBILITY:
--------------
* Tested on Windows 10 and Windows 11
* Compatible with QSpice all versions
* Works with MSVC and MinGW compilers
* Requires C++11 or later
