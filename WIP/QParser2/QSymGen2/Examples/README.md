# QParser2 Project &mdash; QSymGen2 Examples

This folder contains example pin definition files as well as generated symbol and schematic files for a few Microchip devices.

# Files
* GPIO_IMPL.qsch &mdash; Common GPIO circuit.
* PIC16F1521x.* &mdash; PIC16F15213 & PIC16F15214 examples.
* PIC18F4x5x.* &mdash; PIC18F4455 & PIC18F4550 examples.
